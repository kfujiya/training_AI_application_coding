# 週間カレンダー

Open-Meteo の天気と Nager.Date の祝日を、日曜日〜土曜日の今週一週間にまとめるローカルWebアプリです。Node.js 22 以上を使用します。追加パッケージやAPIキーは不要です。

## 起動

Windowsでは **`start-calendar.bat` をダブルクリック**すると、サーバーの起動完了後に既定のブラウザでカレンダーを開きます。起動したウィンドウは開いたまま使用し、終了は `Ctrl+C` です。

BATはデスクトップなど任意の場所へコピー・移動して実行できます。BATと同じフォルダー、直下の `calendar`、直下の `training_AI_application_coding/calendar` の順でアプリを探し、見つからない場合はBATに記録した現在のアプリの絶対パスを使用します。アプリ本体も別の場所へ移した場合は、BATをアプリと同じフォルダーに置くか、BATの `CALENDAR_DIR` を移動先へ書き換えてください。

手動で起動する場合：

PowerShellでこの `calendar` フォルダーに移動して実行します。

```powershell
node server.js
```

ブラウザで **http://127.0.0.1:3000** を開いてください。`index.html` の直接起動では動作しません。終了はターミナルで `Ctrl+C` です。ポートを変更する場合は、`$env:PORT = '3001'` を設定してから起動してください。`npm.cmd start` でも起動できます。

## 操作

1. 「設定」から天気の地域を選択します。任意の地域は地域名・緯度・経度・IANAタイムゾーンを入力します（例: `Asia/Tokyo`）。
2. 追加したい国をチェックして保存します。日本は必須で、他の国は複数選択できます。初回は主要国を表示し、初回取得後に Nager.Date の対応国一覧を反映します。
3. 「情報取得」を押します。天気・対応国一覧・日本と選択国の祝日を取得します。画面起動・設定保存・週の切り替わりでは自動取得しません。
4. 次回取得までの残り時間が `時:分:秒` で表示されます。

## 取得制限と設定の扱い

- 取得開始から3時間は再取得できません。失敗した通信も制限の対象です。複数タブからの同時取得もサーバー側で拒否します。
- 制限時間と取得済みデータは Node.js プロセスのメモリに保持します。画面を閉じたり再読み込みしたりしても解除されません。サーバーを終了・再起動するとリセットされます。
- 時計の変更では制限が解除されないよう、経過時間には単調増加時計を使います。
- 設定はブラウザの `localStorage` に保存します。制限中でも設定を保存できますが、次の「情報取得」まで現在の取得済みデータと地域を表示します。ブラウザごとに設定を保存し、取得制限と最新データは同じサーバーを使う全タブで共有します。
- APIから一部しか取得できなかった場合は、成功した項目と失敗した国・項目を区別します。失敗した項目に古いデータを混ぜません。
- 今週の範囲は設定地域の現地日付を基準とします。日曜から取得日までの過去の天気も Open-Meteo から取得します。地域のタイムゾーンはPCの設定と異なっていても利用できます。
- 祝日は Nager.Date の `Public` を対象とし、一部地域限定の祝日には地域コードを表示します。年をまたぐ週は両年分を取得します。
- 外部APIへの通信には項目ごとに15秒のタイムアウトを設け、最大6件を並列取得します。外部APIに接続できるインターネット環境が必要です。

## 使用API

- [Open-Meteo Forecast API](https://open-meteo.com/en/docs): `https://api.open-meteo.com/v1/forecast`。`start_date` / `end_date`、緯度経度、タイムゾーンを指定し、日別の天気コード・最高/最低気温・最大降水確率を取得します。
- [Nager.Date API](https://date.nager.at/swagger/index.html): `/api/v3/AvailableCountries` と `/api/v3/PublicHolidays/{year}/{countryCode}`。日本は `JP` を使用します。

天気・祝日の内容は各サービスから返された情報をそのまま使用します。対応国や提供内容はサービスの仕様に依存します。非商用利用を想定し、商用利用時は各サービスの利用条件を確認してください。

## テスト

```powershell
node --test
```

Node.js 標準テストで、日曜始まり、地域時差、閏日、年またぎ、複数国の祝日、3時間境界、時計変更、同時押下、通信失敗、HTTPルートを検証します。外部APIはモックを使うため、テストでは外部への通信は発生しません。

## ファイル

- `server.js`: ローカルHTTPサーバーとAPIルート
- `calendar.js`: API取得、週間日付計算、入力検証、メモリ上の取得制限
- `public/`: カレンダー・設定画面
- `test/calendar.test.js`: 自動テスト
