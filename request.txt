今回のプロダクトについて Codex で実施した内容

- Java Servlet と PostgreSQL を使った既存の図書館 Web アプリを確認し、書籍一覧と登録画面の構成を把握しました。
- 書籍の登録ポップアップを用意し、ISBN、タイトル、巻、著者を入力して books テーブルに登録する処理を実装しました。ISBN のハイフン除去、入力形式の検証、重複登録や入力不備のメッセージ表示も追加しました。
- 書籍一覧に巻、著者、貸出中の利用者、未貸出の予約件数を表示します。
- 一覧画面に「貸出/予約」ボタンとポップアップを追加しました。ISBN と利用者氏名を入力すると、書籍が貸出中なら予約を登録し、貸出可能なら貸出記録を登録します。
- 未処理の予約がある書籍は、予約日時が最も新しい利用者に限って貸出できるようにしました。貸出時には loan_records に記録し、該当する予約の loaned_at にも日時を登録します。
- 同じ利用者による未処理の重複予約を防ぎ、書籍単位の行ロックとトランザクションで同時操作による二重貸出を防止します。
- 一覧画面に「返却」ボタンとISBN入力ポップアップを追加しました。返却時は対象書籍の貸出記録に returned_at を登録し、貸出中でない書籍はその旨を通知します。
- 一覧画面に「削除」ボタンとISBN入力ポップアップを追加しました。削除時は書籍に紐付く予約と貸出記録を削除した後、書籍を削除します。処理はトランザクション内で行い、途中で失敗した場合はロールバックします。
- 貸出、予約、返却、削除、入力不備、書籍や利用者が見つからない場合などの結果を画面に表示し、送信後はポップアップを閉じた状態にします。
- Maven で WAR をビルドし、BUILD SUCCESS を確認しました。最新の生成物は target/library-status.war です。
