今回のプロダクトについて Codex で実施した内容

- 既存の Web アプリを確認しました。Java Servlet と PostgreSQL を使い、Servlet がトップ画面の HTML を生成して、books テーブルの書籍情報を表示する構成です。
- トップ画面に「登録」ボタンを追加し、クリックすると ISBN、タイトル、巻、著者を入力するポップアップが開くようにしました。
- 「決定」でフォームを送信し、入力した書籍を PostgreSQL の books テーブルへ登録する処理を追加しました。登録後は一覧画面へ戻ります。
- ISBN のハイフンを除去して保存する処理と、ISBN の形式、タイトル・著者の必須入力、巻の形式の検証を追加しました。
- ISBN の重複や入力不備がある場合にメッセージを表示し、必要に応じて登録ポップアップを再表示するようにしました。
- 書籍一覧に巻と著者を表示するようにしました。
- Maven で WAR をビルドしました。ビルド成果物は target/library-status.war です。ビルドに不足していた Maven プラグインは承認後に取得しました。
- 登録時に「入力内容を確認してください」と表示される原因を調査しました。ISBN が半角数字の13桁、または末尾が数字か X の10文字になっているか、入力した巻が0以上の整数かなど、サーバー側の検証条件を説明しました。
