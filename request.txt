ドール衣装管理アプリで実施した内容
================================

■ プロダクト概要
- ドールのプロフィールと、所有する衣装・色違い・着用可能なドールを管理するWebアプリ。
- 商品デザインと実際の所持アイテムを分け、同じデザインの複数カラーを独立して記録する。
- Java 21、Spring Boot、Thymeleaf、JdbcTemplate、PostgreSQLで構成。
- 既存DBを前提とし、アプリ起動時にテーブルの自動作成・変更・削除をしない。

■ アプリケーション機能
- ドールの一覧・詳細・登録・編集・削除。
- 商品デザインの登録・編集・詳細・削除。商品名、ブランド、カテゴリ、セット名、共通説明を管理。
- 商品デザインごとに複数の所持アイテム（色違い）を登録し、色名、HEXカラーコード、サイズ、個別メモを記録。
- 所持アイテムごとの着用可能ドールを複数選択し、色違いごとに別々に関連付け。
- HEXカラーコードの形式検証と、入力中のカラー見本表示。
- 商品名、ブランド、カテゴリ、メーカー表記サイズ、セット名、対応ドール、カラー名を組み合わせた衣装検索。
- ブランド・購入元、カテゴリは商品デザイン登録時に候補選択または自由入力で追加。既存の管理方法を維持。
- セット名は商品デザイン単位で管理し、同じブランド・セット名のアイテムを確認。
- ドール詳細では、そのドールに個別に関連付けられた所持アイテムのみ表示。
- ColorMagic検索結果から、色見本・HEXコードを確認し、カラーコードをコピー。
- 所持アイテムの登録・編集画面ではカラー名からColorMagicの色候補を表示し、選んだ色をHEX欄へ入力。
- 所持アイテム詳細では配色パレットを検索・保存・表示・削除。同じパレットを同じ所持アイテムへ重複保存しない。
- ColorMagic検索時は日本語キーワードをDeepL API Freeで英語に翻訳。英語検索は翻訳せず実行。
- 日本語検索には環境変数 DEEPL_AUTH_KEY の設定が必要。APIキーをソースコードへ記載しない。
- 検索キーワード・検索結果は衣装詳細ページを離れるとリセット。
- 検索・翻訳APIにタイムアウトとエラー表示を設定。外部APIを利用できない場合も基本の画面操作を維持。

■ UI・デザイン
- 白、クールグレー、チャコールを基調にしたコレクションアーカイブ風デザイン。
- ジェムミント（#36BFB0）、淡いアクアマリン（#D6F4EF）、ディープトルマリン（#167F7A）、アンティークゴールド（#C5A66B）を使用。
- 余白、文字階層、細い罫線を重視し、結晶モチーフや色見本を控えめに追加。
- PC・スマートフォン向けのレイアウトに対応。

■ データベース・マイグレーション
- 既存の大文字・引用符付き命名規則を維持。
- 商品デザインと所持アイテムを分離し、1対多のリレーションを追加。
- 既存衣装1件を商品デザインと所持アイテムへ引き継ぎ、ドールとの紐付けを維持するSQLを作成。
- 旧衣装データの件数とドール紐付け件数を移行前後で照合し、不一致ならロールバックする。
- 移行ファイル：database/migrations/20261102_separate_clothing_designs_and_owned_items.sql
- 所持アイテムに紐づく保存済み配色テーブルを追加するSQLを作成。所持アイテム削除時に関連パレットも削除し、アイテム単位の重複登録を制約で防止。
- 移行ファイル：database/migrations/20261102_add_saved_color_palettes.sql
- 商品デザイン分離マイグレーションは、ユーザーから実行成功の報告あり。
- 保存済み配色テーブルのマイグレーションは、作成・案内済みだが、実DBへの適用完了は未確認。
- DBのバックアップと移行手順をREADME.mdに記載。

■ 外部API・バックエンド
- ColorMagic公式APIの配色検索をJavaバックエンドから呼び出すクライアントを追加。
- 検索・保存・削除用APIエンドポイントを追加。ブラウザーからColorMagicへ直接アクセスしない。
- DeepL API Freeを用いる日本語キーワード翻訳クライアントを追加。
- いずれのAPIキーもソースコードに含めず、DeepLキーは環境変数から取得。
- パレット検索結果はユーザーが保存を選ぶまでDBへ登録しない。
- 保存パレットは色違い所持アイテムごとに分離して保管。

■ 検証
- フォームバリデーション、商品デザインと複数色の所持品・ドール紐付け、ColorMagicクライアント、DeepL翻訳クライアントのテストを実施。
- 最終確認時の対象テスト：11件成功。
- Maven Wrapperによるアプリのパッケージ作成：BUILD SUCCESS。
- ColorMagicの実APIから配色を取得できることを確認。
- DeepLの実APIによる翻訳は、APIキーが未設定の環境では未確認。キー未設定・APIエラー時のテストは実施。
- PostgreSQL上での保存済み配色テーブル作成・画面からの保存／削除動作は、DBマイグレーション適用確認後に実環境で確認が必要。

■ 起動・設定
- Java 21、PostgreSQL、プロジェクト内の Maven Wrapper を使用。
- DB接続先、DBユーザー、DBパスワードは DB_URL、DB_USERNAME、DB_PASSWORD 環境変数で設定。
- 起動コマンド：.\mvnw.cmd spring-boot:run
- ブラウザーで http://localhost:8080 を開く。
- 日本語配色検索を使う場合は、アプリを起動する同じPowerShellで DEEPL_AUTH_KEY を設定。

■ 今回の対象外・注意事項
- 画像アップロード、外部商品検索、オークション連携、配色生成処理は未実装。
- ColorMagicの色候補はカラー名に近い検索結果であり、色名に対する厳密なHEX対応を保証しない。
- PostgreSQLの接続情報やDeepL APIキーなどの秘密情報を、プロジェクトファイルやチャットへ記載しない。
