# Daily Quest

日々の行動をゲームのクエストに見立てて、達成記録・経験値・レベル・連続達成日数を管理する日本語のWebアプリです。HTML、CSS、JavaScriptで構成され、基本機能はブラウザー内で動作します。

## アプリの概要

- デイリークエストとウィークリークエストに挑戦し、「達成」または「見送る」を記録できます。
- デイリークエストは未達成分を1日2回までリセットできます。
- クエストボードから独自のクエストを追加・編集・削除できます。
- クエスト達成で経験値を獲得し、100 XPごとにレベルが上がります。連続達成日数、達成数、実績、履歴も表示します。
- データとテーマ設定はブラウザーの `localStorage` に保存されます。サーバーやアカウント登録は不要です。
- マップ、週間天気、Yahoo!ショッピングの商品検索、周辺スポット検索の連携機能があります。外部サービスを使う機能はネットワーク接続やAPIの利用条件に依存します。
- PCとスマートフォンで使いやすいレイアウトと、ライト／ダークテーマを備えています。

## 作成時に指示した内容の概要

毎日の行動をゲーム感覚で続けられる、ファンタジー風のクエスト管理Webアプリを作ること。日次・週次のクエスト、達成状況、経験値、レベル、連続達成日数、実績、履歴を管理し、ユーザー自身がクエストを編集できるようにすること。ブラウザー内にデータを保存してすぐ使える構成とし、スマートフォンにも対応した見やすい画面にすること。さらに、地域の天気・地図や商品・周辺スポットの検索をクエスト作成につなげる機能を用意すること。

※依頼時のプロンプト原文ではなく、現在のアプリ実装から整理した概要です。

## 起動方法

`index.html` をブラウザーで開いてください。Chrome または Edge を推奨します。データは同じブラウザープロファイル内に保存されます。ブラウザーの保存データを消去すると、アプリの記録も消去されます。

## 外部サービス連携

天気予報には Open-Meteo、地図表示には Google Maps の埋め込みを利用します。商品検索と周辺スポット検索には Yahoo! のAPIを利用します。外部連携はAPI側の提供状況、利用条件、ブラウザーの通信制限により利用できない場合があります。APIを利用する際は、画面内の設定と各サービスの最新の利用条件を確認してください。

## 主なファイル

- `index.html`：画面構成、クエスト一覧、進捗・履歴表示、ダイアログ
- `styles.css`：配色、テーマ、レスポンシブレイアウト
- `app.js`：クエスト管理、達成記録、経験値・レベル・実績、`localStorage` 保存
- `integrations.js`：地図と週間天気の表示
- `yahoo.js`：Yahoo!ショッピング商品検索と周辺スポット検索
- `browser-smoke.cjs`：ブラウザー操作による動作確認用スクリプト

## 動作確認スクリプト

Node.js と Google Chrome がある環境では、プロジェクトのディレクトリで次を実行できます。

```powershell
node browser-smoke.cjs
```
